# Klima Doma — porovnání návrhů

Tento adresář obsahuje sedm samostatných návrhů, každý ve vlastní podsložce s HTML, CSS, zásadami a README. `index.html` přesměruje na místní přehled `porovnani.html`.

## GitHub Pages

Veřejná verze se publikuje z `site-source.zip` v samostatném repozitáři `I-C-N-C/klimadoma-porovnani` přes workflow v `.github/workflows/pages.yml`. Po zveřejnění je přehled na `https://i-c-n-c.github.io/klimadoma-porovnani/`.

Formuláře jsou pouze ukázkové a nic neposílají. Stránky záměrně obsahují pracovní zásady s údaji `XXX`; před použitím jako skutečného firemního webu je nahraď ověřenými údaji. Fotografie se načítají z Wixu.
