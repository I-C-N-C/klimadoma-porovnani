# Klima Doma — porovnání návrhů

**Veřejný přehled:** https://i-c-n-c.github.io/klimadoma-porovnani/

Projekt obsahuje šest samostatných designů. `site-source.zip` je zdrojový balíček; GitHub Actions jej rozbalí a publikuje na GitHub Pages. Workflow je v `.github/workflows/pages.yml`.

Kontaktní formuláře jsou pouze demo a nic neodesílají. Stránky ochrany osobních údajů jsou pracovní návrhy s hodnotami `XXX`; nejsou připravené k použití jako produkční právní dokumenty. Fotografie se načítají z Wixu.
